# CrowdTune issues

Report a problem with [CrowdTune](https://crowdtune.live), or suggest something it should do.

This repository holds issues only. CrowdTune's source code is not here.

## Before you open an issue

- **Search first.** Someone may have reported it already. Add a 👍 to that issue instead of opening a new one.
- **One problem per issue.**
- **Leave out personal data.** Do not paste email addresses, guest-pass links, event links you want to keep
  private, or screenshots showing other people's names.

## Where else to go

| You want to | Go to |
| --- | --- |
| Report a security vulnerability | Email privacy@contact.crowdtune.live. Please do not open a public issue. |
| Report abusive or illegal content in an event | Use **Report** in the event, or email abuse@contact.crowdtune.live |
| Ask about your data, or delete your account | Email privacy@contact.crowdtune.live |

## What happens next

Issues are read and labelled within a few days. A fix ships to crowdtune.live when it is ready, and the issue is
closed with a note saying so.
